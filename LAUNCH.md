# Launch

Machine-driven mode: no posts, outreach or messages are sent by anyone. Distribution runs through the product and search. This file records what is live and the human-only options for later.

## Live

- URL: https://theguysaccount.github.io/family-creed-generator/
- Distribution built in: credit line on every print (removable by the user), share links whose main button is "Make one for your family", invite links for relatives, 50+ search pages with titles, descriptions, canonical URLs, Open Graph cards and structured data, a sitemap, and IndexNow pings on every deploy.

## Production deploy steps (after a domain is chosen)

See OPERATIONS.md → "Keys Jack can turn later" → 1 for the exact DNS records and commands. Summary: buy one of familycreed.app / makeyourcrest.com / crestandcreed.org, add GitHub Pages' four A and four AAAA records plus a `www` CNAME, set the Pages custom domain, set `FCG_SITE_URL`, redeploy. Redirect any other domains with a 301 to the chosen one.
